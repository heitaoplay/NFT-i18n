# NFT — Nest of Fluffy Treasures

> Мод для Bondage Club. Багатомовне README:
> [English](README.md) · [简体中文](README.cn.md) · [繁體中文](README.tw.md) · [Deutsch](README.de.md) · [Français](README.fr.md) · [Русский](README.ru.md)

NFT дозволяє **зберігати та завантажувати предмети `ItemHandheld` / `ItemMisc`** з їх
повним виглядом, даними творця та властивостями, щоб ви могли змінювати
улюблені предмети у слотах, не втрачаючи їхніх налаштувань.

## Можливості

- Збереження поточного екіпірованого предмета в руках / іншого у іменований слот.
- Завантаження / керування збереженими предметами через перетягувану плаваючу кнопку.
- Повна попередня перевірка вигляду, кольору, творця та розширених властивостей.
- Експорт / імпорт збережень у JSON для резервного копіювання або обміну.
- Запам'ятовує положення плаваючої кнопки між сесіями.

## Встановлення

1. Встановіть менеджер користувацьких скриптів: **Tampermonkey** (рекомендовано) або **Violentmonkey**.
2. Натисніть **[Встановити NFT.user.js](https://raw.githubusercontent.com/heitaoplay/NFT-i18n/main/NFT.user.js)** — менеджер одразу відкриє вікно встановлення.
   - Це **самооновлюваний** інсталятор: `@updateURL` / `@downloadURL` вказують на
     вихідний файл на GitHub, тому Tampermonkey автоматично перевіряє оновлення.
   - При кожному запуску він завантажує мод (`NFT.js`) з **CDN jsDelivr**
     (`https://cdn.jsdelivr.net/gh/heitaoplay/NFT-i18n@main/NFT.js`), який завжди віддає останню опубліковану версію.
3. Відкрийте Bondage Club, увійдіть — з'явиться маленька плаваюча кнопка.
   Натисніть (або перетягніть) її, щоб відкрити «Held Item Saver».

> **Для розробників:** `NFT-dev.js` — локальна збірка (ім'я моду `NFT - DEV`),
> яку можна завантажувати напряму за адресою `file://` без CDN.

## Інтернаціоналізація

Мод під час виконання слідує `TranslationLanguage` Bondage Club і для непідтримуваних
кодів повертається до англійської. Джерела перекладу містяться в `locales/`:

| Файл       | Мова       | Код BC |
|------------|------------|--------|
| `en.json`  | English    | EN     |
| `de.json`  | Deutsch    | DE     |
| `fr.json`  | Français   | FR     |
| `ru.json`  | Русский    | RU     |
| `cn.json`  | 简体中文    | CN     |
| `tw.json`  | 繁體中文    | TW     |
| `ua.json`  | Українська | UA     |

Ключі плоскі з крапковим розділенням (напр. `save.button`, `load.apply`) і використовують
маркери `{placeholder}` для значень часу виконання. Дані перекладу вбудовуються в
одинарний файл `NFT.js` на етапі збірки, тому **немає звернень у runtime**, і
розгорнутий файл на 100 % складається з ASCII (безпечно за будь-якого кодування на будь-якому хості).

## Розробка

```bash
node test-locales.cjs   # перевірити рівність ключів і плейсхолдерів за мовами
node build.cjs          # вбудувати локалі в NFT.js і заново згенерувати NFT-dev.js
node test-i18n.cjs      # перевірити поставлений рушій T() під час виконання
```
