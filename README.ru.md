# NFT — Nest of Fluffy Treasures

> Мод для Bondage Club. Многоязычное README:
> [English](README.md) · [简体中文](README.cn.md) · [繁體中文](README.tw.md) · [Deutsch](README.de.md) · [Français](README.fr.md) · [Українська](README.ua.md)

NFT позволяет **сохранять и загружать предметы `ItemHandheld` / `ItemMisc`** с их
полным внешним видом, данными создателя и свойствами, чтобы вы могли менять
любимые предметы в слотах, не теряя их настройки.

## Возможности

- Сохранение текущего экипированного предмета в руках / прочего в именованный слот.
- Загрузка / управление сохранёнными предметами через перетаскиваемую плавающую кнопку.
- Полный предпросмотр внешнего вида, цвета, создателя и расширенных свойств.
- Экспорт / импорт сохранений в JSON для резервного копирования или обмена.
- Запоминает положение плавающей кнопки между сессиями.

## Установка

1. Установите менеджер пользовательских скриптов: **Tampermonkey** (рекомендуется) или **Violentmonkey**.
2. Откройте [`NFT.user.js`](NFT.user.js) и позвольте менеджеру установить его.
   - Это **самообновляющийся** установщик: `@updateURL` / `@downloadURL` указывают на
     исходный файл на GitHub, поэтому Tampermonkey автоматически проверяет обновления.
   - При каждом запуске он загружает мод (`NFT.js`) с **CDN jsDelivr**
     (`https://cdn.jsdelivr.net/gh/heitaoplay/NFT-i18n@main/NFT.js`), который всегда отдаёт последнюю опубликованную версию.
3. Откройте Bondage Club, войдите в аккаунт — появится маленькая плавающая кнопка.
   Нажмите (или перетащите) её, чтобы открыть «Held Item Saver».

> **Для разработчиков:** `NFT-dev.js` — локальная сборка (имя мода `NFT - DEV`),
> которую можно загружать напрямую по адресу `file://` без CDN.

## Интернационализация

Мод во время выполнения следует `TranslationLanguage` Bondage Club и для
неподдерживаемых кодов возвращается к английскому. Исходники переводов находятся в `locales/`:

| Файл       | Язык       | Код BC |
|------------|------------|--------|
| `en.json`  | English    | EN     |
| `de.json`  | Deutsch    | DE     |
| `fr.json`  | Français   | FR     |
| `ru.json`  | Русский    | RU     |
| `cn.json`  | 简体中文    | CN     |
| `tw.json`  | 繁體中文    | TW     |
| `ua.json`  | Українська | UA     |

Ключи плоские с точечным разделением (напр. `save.button`, `load.apply`) и используют
токены `{placeholder}` для значений времени выполнения. Данные перевода встраиваются в
одиночный файл `NFT.js` на этапе сборки, поэтому **нет обращений в runtime**, и
развёрнутый файл на 100 % состоит из ASCII (безопасен при любой кодировке на любом хосте).

## Разработка

```bash
node test-locales.cjs   # проверить равенство ключей и плейсхолдеров по языкам
node build.cjs          # встроить локали в NFT.js и заново сгенерировать NFT-dev.js
node test-i18n.cjs      # проверить поставляемый движок T() во время выполнения
```
